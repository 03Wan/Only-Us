# 心愿、故事、车票与小屋设置修复

日期：2026-11-06。验收范围为本次用户提供的五张截图对应的本机体验。

## 修改结果

- 默认和新增心愿使用同一个卡片模板，支持备注、编辑、勾选完成；新增心愿支持删除。兑现数量包含新增项，原有勾选与文字保留。
- “留下一页故事”打开完整表单，包含标题、日期、天气、地点、正文、照片和照片说明。真实记录按手账卡片显示，照片可预览，自己的故事可编辑、删除。旧文字记录仍能显示，可通过编辑补上图片等信息。新故事输入时保存草稿。
- “见面”页提供真实的车票记录与设置表单，包含车次、车站、座位、出发/到达日期和时间、状态。支持跨天行程，并将到达日期同步到见面倒计时。已有车票可再次修改。
- “小屋”和“我们”页顶部常驻“小屋设置”，可进入资料、纪念日、见面、故事、心情和连接设置。资料页改为可持续使用的“小屋资料设置”，不再使用一次性开通文案。纪念日卡片旁也提供修改入口。
- 编辑浮层打开时隐藏自定义底栏，关闭时恢复；表单可滚动，保存按钮固定在浮层底部，校验失败保留输入内容。

## 验证

- `npm run check`：路由、资源与 TypeScript 检查通过。
- `npm test`：72 项通过，包含图文故事往返保存/编辑、草稿与写入失败、心愿合并与计数、跨天车票、云端作者权限及照片 ID 保留。
- `npm run check:native`：官方 WXML/WXSS 编译器检查 37 个文件，0 错误。
- `npm run qa:static`：260 个交互元素，0 个缺失处理函数。
- `npm run qa:features`：开发者工具真实 AppService 导航和保存流程通过；7 个状态分别在 320×568、390×844、430×932 下验证，共 21 组，无横向溢出，浮层保存按钮可命中。
- 截图与机器结果：`artifacts/feature-editors/`。其中 `story.png` 与本次“初次相识”参考图使用相同的示例内容和本地素材，仅供验收。测试后逐键恢复所有原有 `only-us:` 缓存。

本次运行和界面验收使用本机模式。云端新增接口已通过模拟存储的业务测试，尚未部署云函数、进行双手机联调，未验证真机系统键盘/相册选择器。新增业务没有修改现有云数据结构版本；旧数据通过可选字段兼容。切换云端前需部署更新后的 gateway。

## 实现位置

编辑器状态及保存逻辑：`miniprogram/shared/feature-editors.ts`；页面生成与兼容改造：`scripts/feature-views.cjs`，由原有 `qa-views.cjs` 调用。重新生成页面仍会保留本次卡片与编辑器。
