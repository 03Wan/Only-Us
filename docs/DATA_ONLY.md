- 本机模式不再生成 DEMO 邀请码或模拟绑定成功；双人邀请与确认必须经过云端业务。
- 删除运行包内 17 张只用于示例的照片与旧的设计默认值模块。保留实际页面使用的 3 张装饰插画，以及正常功能图标。

## 旧缓存处理

本机保存命名空间由 `only-us:mock:v1:` 迁至 `only-us:local:v2:`。首次启动按已知示例的文本指纹清理旧字段，保留用户写入的文字、照片和记录；全部新值写入成功后才移除旧键。中途写入失败时保留原键并允许重试。

已改写的资料、便签和心愿均保留。对于已自定义资料中保存的日期，无法证明是示例就予以保留，不按日期字符串批量删除。只含标题的旧信件元数据不会伪造成完整信件。

清理前的本机恢复副本仅存放于忽略目录 `artifacts/qa-private-backups/`，用于误删恢复，不参与应用加载，也不应上传。原始 Stitch 设计与必要的测试样本属于开发参考，不作为运行时数据重新注入。
