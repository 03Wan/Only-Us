# 投递选择、纪念日与小屋设置

2026-11-07，根据四张反馈截图修改。

- 投递方式使用整卡按钮，圆点、勾选和配色跟随实际状态。“立即送达”收起日期选择；“未来开启”仅保留一个日期入口，最早可选明天。
- 四张纪念日卡片全部使用原生日期选择器，选定即保存。相识与相恋日期不能晚于今天。百天与周年默认由相恋日期计算，分别修改后保留自定义日期，不改动其他纪念日；修改小屋资料也不会丢失自定义日期。
- 小屋设置使用空间信息卡、双人头像和两组菜单，每项显示独立图标、标题与说明，内容支持滚动。
- 见面卡片分开显示标题、日期与倒计时；没有日期时提供明确的设置入口，整卡保持可点击。

## 验证

- `npm run check`、`npm run qa:static` 通过。
- `npm run check:native`：37 个原生文件编译，0 错误；微信开发者工具重新编译通过。
- `npm test`：95 项通过，包含独立纪念日持久化、资料修改保留自定义日期、无效日期及写入失败回滚、云端双人快照和立即发送草稿回归。
- `npm run qa:cards`：模拟器实际点击投递选项和页面入口，四张纪念日卡片实际弹出原生日期选择器；日期保存通过页面事件处理函数验证。320×568、390×844、430×932 三种尺寸共 18 组检查无横向溢出。
- 模拟器测试前备份 `only-us:` 缓存，测试后逐键恢复并核对。截图和结果在 `artifacts/card-refinements/`。

默认仍为本机模式。云端代码已支持 `milestoneDate` 操作及独立日期快照，并通过内存后端测试；启用云端模式时需更新 `gateway` 云函数，本次未部署云函数或进行真实双设备联调。
