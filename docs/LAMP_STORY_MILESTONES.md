# 台灯、故事表单与初次相识卡片

2026-11-06，按用户本轮三张截图完成修改。

- 台灯开关同时改变房间底图亮度、饱和度、冷色暗部和灯下暖光。所有照明层位于热点按钮下方，关灯仍可操作照片墙、信箱等入口。日间和夜间均能开关台灯。
- 故事表单将日期与天气并排、地点放在完整一行；输入框去掉上下内边距并统一行高，修正文字偏下的问题。正文输入区缩为 132px，照片入口上移，按钮增加相机图标；底部保存栏继续固定显示，照片说明和草稿提示可滚动查看。
- 纪念日区域补充“故事开篇 / 初次相识”卡片，与正式在一起、百天纪念、周岁年鉴组成四宫格。点击新卡片可直接设置或修改日期，资料设置页也提供对应的可选日期字段。未填写时显示设置入口，不自动填入示例日期。
- `firstMet` 为新增可选资料字段，本机与云端业务均兼容旧数据。旧客户端调用资料保存时未传此字段，不会清掉已有相识日期；不晚于今天的合法日期才可保存。
