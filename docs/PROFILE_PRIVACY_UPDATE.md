# 心情表情、头像入口与设置说明

2026-11-07。

- 小屋中的双方心情增加对应表情：开心 😊、平静 😌、疲惫 😴、想你 🥰、需要抱抱 🫂、想独处 🌙。状态与碎碎念分开展示；未连接或未分享的对方不会显示推测出的心情表情。服务端仅在对方启用分享时返回心情类型。
