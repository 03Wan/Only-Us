# 设置入口、提示与便签 / 标签面板

2026-11-06。本次根据用户新增的三张截图调整现有界面。

- 去掉“小屋”和“我们”正文顶部独占一行的设置长按钮，将设置图标放入顶部导航、微信胶囊预留区域左侧。点击图标或这两页的标题可打开原有设置面板。
