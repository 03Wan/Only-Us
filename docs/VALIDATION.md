## 运行过程中修复

- 导入子目录且未开启 TS 时会寻找 index.js；推荐根目录导入，根配置启用 TypeScript。用户选择根目录后，没有继续修改子目录入口。
- SDK 状态实际在 `D:\CDriveRelief`，CLI 读取 C 盘旧状态误报端口关闭。使用仅在本次会话生效的路径适配，读取真实已开启的 `.ide-status`；用户提供的 13197 端口正常监听。没有伪造端口开关，没有修改安全设置。
- 清除 WXSS 不接受的 Web 通配选择器和 selection/hover/focus 规则；模板表达式中的 `&&` 与字符串不再错误编码为 HTML 实体；35 原生文件均可编译。
- 为 CSS 渐变初始化位置变量，恢复见面/我们/锁定信的深色背景与按钮渐变；消除本项目状态提示组件的非法标签选择器警告。
- 样式编译错误后的工具缓存曾保留旧状态，清理的是当前项目编译缓存，没有清理本地草稿/登录/业务数据。验收时暂时关闭热重载，完成后恢复用户原来的开启状态。
